# UroRounds - Proyecto

Este ZIP contiene todo el código fuente listo para desarrollo local o despliegue en Vercel.

## Instalación Local

1. Asegúrate de tener **Node.js** instalado.
2. Abre una terminal en esta carpeta.
3. Instala las dependencias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

## Despliegue en Vercel

1. Sube este código a un repositorio de GitHub.
2. Importa el proyecto en Vercel.
3. En la configuración de **Environment Variables** en Vercel, copia el contenido del archivo `vercel_env.txt` que encontrarás en la raíz del proyecto.
4. ¡Listo!
